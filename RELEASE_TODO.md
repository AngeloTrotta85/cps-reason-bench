# Author Decisions Before Publication

Only external publication decisions remain here, not implementation tasks.

1. Choose the public repository host, URL and visibility. None is asserted.
2. Approve the first public release tag/version policy. Existing package `0.5.0`
   is preserved; no new tag or publication has been created.
3. Approve author names, affiliations, preferred citation and any archival DOI.
   No `CITATION.cff` with invented metadata is provided.
4. Decide whether to publish a separately reviewed scientific results/artifact
   bundle, and its licensing/privacy/archival terms. Raw campaign evidence is not
   part of this software candidate.

The existing MIT software license and contributor copyright are retained exactly;
there is no unresolved inferred software-license choice. Changing that established
license or adding a third-party artifact license would require author review.
